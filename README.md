# gubuk_cinema

A mobile cinema booking application built with **Flutter** (frontend) and **Next.js** (backend).  

---

| **Prompt (Command / Step)** | **Documentation / Result** |
|------------------------------|-----------------------------|
| `git clone https://github.com/rizaton/gubuk_cinema.git` | Clone the repository to your local machine |
| `cd gubuk_cinema/backend` | Navigate to the Next.js backend |
| `npm install` | Install backend dependencies |
| `npm run dev` | Start the Next.js backend server |
| `cd ../frontend` | Navigate to the Flutter frontend |
| `flutter pub get` | Install Flutter dependencies |
| `flutter run` | Run the Flutter app on emulator or device |
| Open the app on mobile | Access the cinema booking interface |

---

## Features
- 🎬 Browse available movies  
- 🕒 Showtimes and schedules  
- 🎟️ Book tickets  
- 📱 Cross-platform (Android & iOS)  

---

## Requirements
- **Backend**: Node.js, npm, Next.js  
- **Frontend**: Flutter SDK, Dart  
- Emulator or physical device for testing
